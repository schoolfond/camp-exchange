# Обмен лагерями — Школа Фонда Потанина 2026

Неофициальный сервис для участников, желающих обменяться назначенными лагерями.

## Архитектура

| Компонент | Технология |
|-----------|-----------|
| Фронтенд   | Статический HTML/CSS/JS на **GitHub Pages** |
| Бэкенд     | **Google Apps Script** (Web App) |
| База данных | **Google Таблица** (3 листа) |

## Инструкция по развёртыванию

### 1. Создайте Google Таблицу

1. Откройте [sheets.google.com](https://sheets.google.com) → Создать новую таблицу
2. Переименуйте листы (внизу страницы):
   - `Лист1` → `camps`
   - Добавьте лист `participants`
   - Добавьте лист `offers`

### 2. Заполните структуру листов

#### Лист `camps` (заголовки в первой строке):
| name | dates | region |

#### Лист `participants` (заголовки в первой строке):
| id | name | university | region | city | camp |

#### Лист `offers` (заголовки в первой строке):
| timestamp | participantId | name | fromCamp | toCamp | contact | note | status |

### 3. Загрузите данные участников

В лист `participants` вставьте данные из PDF (скопируйте столбцы: ФИО, Вуз, Регион, Город, Лагерь).

В лист `camps` вставьте список всех лагерей.

### 4. Подключите Google Apps Script

1. В Google Таблице: **Расширения → Apps Script**
2. Удалите весь код в редакторе
3. Скопируйте содержимое файла `backend.gs` (из этого репозитория) и вставьте
4. Нажмите **Сохранить** (дискета)
5. Нажмите **Развернуть → Новое развертывание**
6. Выберите тип: **Веб-приложение**
7. Настройки:
   - Выполнять от: **Меня**
   - Доступ: **Все** (или «Все, у кого есть ссылка»)
8. Нажмите **Развернуть**
9. **Скопируйте URL веб-приложения** (выглядит как `https://script.google.com/macros/s/.../exec`)

### 5. Настройте фронтенд

1. Откройте файл `index.html`
2. Найдите строку: `const API_URL = 'https://script.google.com/macros/s/AKfycbz...';`
3. Замените на URL из шага 4
4. Сохраните

### 6. Разместите на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите `index.html` в корень репозитория
3. В настройках репозитория: **Settings → Pages**
4. Выберите ветку `main`, папка `/ (root)`, нажмите Save
5. Через минуту сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/РЕПОЗИТОРИЙ/`

### 7. Готово!

Сайт читает данные из Google Таблицы и отображает:
- Список участников с фильтрацией по лагерю
- Заявки на обмен
- Автоматически найденные мэтчи (встречные заявки)

## Тестирование локально

Откройте `index.html` в браузере. Данные не загрузятся (CORS для локального файла), но интерфейс будет виден.

Для полноценного тестирования — загрузите на GitHub Pages.

## Безопасность

- Google Apps Script работает в вашем аккаунте Google
- Доступ на чтение — для всех (через веб-приложение)
- Запись (создание заявок) — через POST-запросы к скрипту
- Контактные данные участников видны всем посетителям сайта
